# Behavioral / anti-regression tests

Тесты проверяют не способность пересказать lesson, а применение опыта в новой похожей ситуации.

Каждый case должен иметь:
- входную ситуацию;
- expected behavior;
- типичную неправильную реакцию;
- PASS criterion;
- FAIL criterion;
- source experience/evidence;
- applicability boundary.
