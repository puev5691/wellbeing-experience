# Corpus model: ПЕНСИОНЕРЫ + БОЛЬНИЦА + LIVE

## 1. ПЕНСИОНЕРЫ

Назначение: успешные или достойно отработавшие экземпляры, завершившие существенные задачи.

Что извлекать:
- рабочие стратегии;
- причины удачных решений;
- проверенные процедуры;
- эволюцию архитектуры;
- сигналы, позволившие найти проблему;
- способы проверки результата.

Риск смещения: если использовать только ПЕНСИОНЕРОВ, база будет переоценивать успешные траектории.

## 2. БОЛЬНИЦА

Назначение: pathology corpus.

Сюда относятся сохранённые экземпляры, у которых наблюдались:
- игнорирование источников и инструкций;
- болтовня вместо действия;
- выдумывание фактов/статусов;
- role drift;
- повторение уже известных ошибок;
- потеря причинности;
- неуместное повышение confidence;
- путаница publication/delivery/receipt/acceptance;
- degradation после длинной работы;
- иные подтверждённые failure patterns.

БОЛЬНИЦА особенно ценна для:
- `prohibited_repeat`;
- failure signatures;
- anti-regression tests;
- initiation admission tests;
- раннего обнаружения деградации экземпляра.

Сам факт помещения чата в БОЛЬНИЦУ не доказывает конкретную причину сбоя. Причина фиксируется только если её можно подтвердить содержимым истории/evidence.

## 3. LIVE EXPERIENCE DELTAS

Новый основной режим.

После значимого эпизода current-writer фиксирует короткую delta, пока причинность ещё находится в активном контексте:

`ситуация → ожидание → действие → наблюдение → ошибка/успех → корректировка → lesson → next_time_behavior`

Не фиксировать каждую команду и реплику. Delta нужна только при появлении повторно используемого знания.

## 4. Нормализация

Все три корпуса после extraction приводятся к общей Experience Card schema.

Старый чат остаётся provenance. Карточка опыта является производным объектом и обязана ссылаться на evidence/эпизод.

## 5. Статусы

- `candidate` — извлечено, но не подтверждено повторением/независимой проверкой;
- `reusable` — пригодно для повторного применения в указанной границе;
- `requires-current-check` — историческое знание, перед применением нужен свежий read-only check;
- `historical` — факт прошлого;
- `superseded` — заменено более новым lesson;
- `conflicted` — есть противоречащий опыт, требуется разбор;
- `unknown` — причинность или граница не восстановлена.
