# RAW corpus

В этом слое хранятся или адресуются исходные исторические материалы.

Категории:
- `pensioners/` — успешные/завершившие работу экземпляры;
- `hospital/` — pathology/failure cases;
- `other/` — прочие исторические траектории.

RAW не является current truth.
RAW не редактируется ради «улучшения» истории.
Для больших чатов допустим locator на внешний immutable объект вместо физического копирования в Git.

Перед публичной публикацией любого RAW проверить наличие секретов, приватных данных и сторонних материалов, которые нельзя публиковать полностью.
