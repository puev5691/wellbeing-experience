# Extracted experience

Этот слой хранит производные объекты опыта после extraction и проверки provenance.

Предполагаемые типы:
- experience cards;
- reusable lessons;
- runbooks/checklists;
- contradiction/supersession records;
- role-specific indexes.

RAW-история остаётся отдельно. Здесь не хранится current project state только потому, что он когда-то встречался в старом чате.
